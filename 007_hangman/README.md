# Day 7: 🎯 Hangman

## Overview

A full console Hangman game with word selection, lives, guessed letters, and input validation.

This project is part of my **100 Days of Code: Python Bootcamp** progress.

---

## Concepts practiced

- loops
- lists
- modules
- random word selection
- input validation
- game state

---

## Files

| File | Purpose |
|---|---|
| `main.py` | The final Hangman game. |
| `art.py` | The game logo and hangman stages. |
| `words.py` | The word bank used by the game. |

---

## How to run

From this folder:

```bash
python main.py
```

Or from the repo root:

```bash
cd 007_hangman
python main.py
```

---

## Example run

```text
Welcome to the Hangman Game!

Word: ______
Lives remaining: 6
Guessed letters: None
Guess a letter:
```
