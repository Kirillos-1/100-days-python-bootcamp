# Day 3: 🚀 Space Station Escape

## Overview

A branching text adventure inspired by Treasure Island, rebuilt with a space-station theme.

This project is part of my **100 Days of Code: Python Bootcamp** progress.

---

## Concepts practiced

- conditional statements
- `if` / `elif` / `else`
- nested decisions
- input normalization
- story design

---

## Files

| File | Purpose |
|---|---|
| `main.py` | The final interactive story game. |
| `section_code.py` | Conditional logic exercises from the lesson. |

---

## How to run

From this folder:

```bash
python main.py
```

Or from the repo root:

```bash
cd 003_treasure_island
python main.py
```

---

## Example run

```text
Mission: Escape before the station explodes 💥
Choose wisely... or drift forever in space.

You wake up in the command center.
Do you go LEFT to engineering or RIGHT to the dark tunnel?
```
