# Day 2: 🧾 Tip Calculator

## Overview

A bill-splitting calculator that handles tips and formats money cleanly.

This project is part of my **100 Days of Code: Python Bootcamp** progress.

---

## Concepts practiced

- data types
- type conversion
- arithmetic operators
- f-strings
- rounding/formatting

---

## Files

| File | Purpose |
|---|---|
| `main.py` | The final bill-splitting calculator. |
| `section_code.py` | Practice with data types and operations. |

---

## How to run

From this folder:

```bash
python main.py
```

Or from the repo root:

```bash
cd 002_tip_calculator
python main.py
```

---

## Example run

```text
Welcome to the tip calculator!

What was the total bill? $150
How much tip would you like to give? 10, 12, or 15? 12
How many people to split the bill? 5

Each person should pay: $33.60
```
