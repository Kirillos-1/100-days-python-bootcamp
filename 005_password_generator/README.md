# Day 5: 🔐 PyPassword Generator

## Overview

A random password generator that mixes letters, symbols, and numbers.

This project is part of my **100 Days of Code: Python Bootcamp** progress.

---

## Concepts practiced

- loops
- `range()`
- `random.choice()`
- `random.shuffle()`
- lists
- `string` module

---

## Files

| File | Purpose |
|---|---|
| `main.py` | The final password generator. |
| `section_code.py` | Loop and random practice snippets. |

---

## How to run

From this folder:

```bash
python main.py
```

Or from the repo root:

```bash
cd 005_password_generator
python main.py
```

---

## Example run

```text
Welcome to the PyPassword Generator!

How many letters would you like? 8
How many symbols would you like? 2
How many numbers would you like? 3
Your password is: a9B!z2Q#m7K
```
