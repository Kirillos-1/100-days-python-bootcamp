I am not treating this like a folder dump. This is my learning trail: every small project, every concept, every bug, every refactor, and every step that turns beginner practice into real programming skill.

---

## 🚀 Why this repo exists

I started this challenge to build strong Python fundamentals by actually writing code every day, not just watching videos or collecting certificates.

The goal is simple:

- build real projects consistently,
- document what I learn,
- keep my progress visible,
- improve my problem-solving mindset,
- and make my GitHub reflect the actual journey.

## ▶️ How to run any project

Clone the repo:

```bash
git clone https://github.com/YOUR_USERNAME/100-days-python-bootcamp.git
cd 100-days-python-bootcamp
```

Go into any completed day folder:

```bash
cd 009_secret_auction
python main.py
```

On some systems, use:

```bash
python3 main.py
```

> Some days may include extra practice files like `section_code.py`. Those files are kept because they show the learning process, not only the final answer.
