## ▶️ How to run any project

Clone the repo:

```bash
git clone https://github.com/YOUR_USERNAME/100-days-python-bootcamp.git
cd 100-days-python-bootcamp
```

Go into any day folder:

```bash
cd 009_secret_auction
python main.py
```

On some systems, use:

```bash
python3 main.py
```

> Day 6 currently uses `section_code.py` instead of `main.py`, so run it with `python section_code.py`.
