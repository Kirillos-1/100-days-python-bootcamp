# Day 9: 🏆 Secret Auction

## Overview

A private bidding game that stores bidders in a dictionary and finds the highest bid.

This project is part of my **100 Days of Code: Python Bootcamp** progress.

---

## Concepts practiced

- dictionaries
- functions
- input validation
- loops
- tuples
- screen clearing

---

## Files

| File | Purpose |
|---|---|
| `main.py` | The final secret auction program. |
| `art.py` | The console logo. |
| `section_code.py` | Dictionary and nested data structure practice snippets. |

---

## How to run

From this folder:

```bash
python main.py
```

Or from the repo root:

```bash
cd 009_secret_auction
python main.py
```

---

## Example run

```text
Welcome to the secret auction program!

What's the bidder name: Mina
What's the bid amount: $250
Are there any other bidders? Type 'yes' or 'no': no

The winner is Mina with a bid of $250.00
```

- How to validate text and numeric input.
- How to return multiple values from a function using a tuple.
