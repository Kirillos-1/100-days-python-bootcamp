# Day 1: 🎸 Band Name Generator

## Overview

A tiny first program that turns two simple inputs into a band name.

This project is part of my **100 Days of Code: Python Bootcamp** progress.

---

## Concepts practiced

- `print()`
- `input()`
- variables
- string concatenation
- basic program flow

---

## Files

| File | Purpose |
|---|---|
| `main.py` | The final mini-project. |
| `section_code.py` | Small practice snippets from the lesson. |

---

## How to run

From this folder:

```bash
python main.py
```

Or from the repo root:

```bash
cd 001_band_name_generator
python main.py
```

---

## Example run

```text
Welcome to the Band Name Generator!

What's the city you grew up in? Cairo
What's the name of your pet? Luna

Your band name could be: Cairo Luna
```
