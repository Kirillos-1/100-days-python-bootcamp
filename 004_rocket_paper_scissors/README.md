# Day 4: 🛡️ Rock Paper Scissors

## Overview

A fantasy-style Rock Paper Scissors game using Shield, Dragon, and Sword ASCII art.

This project is part of my **100 Days of Code: Python Bootcamp** progress.

---

## Concepts practiced

- randomization
- lists
- indexing
- module imports
- game rules
- ASCII art

---

## Files

| File | Purpose |
|---|---|
| `main.py` | The final game logic. |
| `ascii_art.py` | Game logo, win/lose/draw banners, and player choice art. |
| `section_code.py` | Random module practice snippets. |

---

## How to run

From this folder:

```bash
python main.py
```

Or from the repo root:

```bash
cd 004_rocket_paper_scissors
python main.py
```

---

## Example run

```text
What do you want to choose?
0 -> Rock (Shield)
1 -> Paper (Dragon)
2 -> Scissors (Sword)
```

- How to store related art in lists.
